# Source provenance

The player and optional Omarchy integration originate from DNBRADIO's private
`dnbradio/dnbradio-laravel` repository, commit
`bb250e49752b5f0dc66fc08d7bcc231e32c43684`, path `integrations/omarchy/dnbradio`.
Omarchy plugin 0.5.0 adds the label and release links from commit
`5f6431d3b82d7729010ec33bf4f0dfe6b3d6e7be` of the same path.

The standalone application replaces Omarchy UI controls, shell IPC, storage,
notifications, and window management with Qt facilities. The original Omarchy
integration remains available under `integrations/omarchy`.

This repository and its release artifacts remain private. No public distribution
license has been selected. Third-party Qt runtime components retain their own licenses.
