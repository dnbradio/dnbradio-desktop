DNBRADIO for Windows

Requires 64-bit Windows 10 (1809 or newer) or Windows 11.

Extract the entire ZIP, then double-click DNBRADIO/dnbradio.exe.
Keep the EXE together with all its DLLs and folders. No Qt installation,
administrator access, or separate Visual C++ runtime installation is required.
This build is not code-signed yet, so Windows SmartScreen may show an
unknown publisher warning. Click More info, then Run anyway.

Choose a station and press Play. Audio does not start automatically.
Click the DNBRADIO notification-area icon for the mini player. Windows may
place it in the hidden-icons menu. Right-click for Mini player, Open player,
or Quit. Closing the full window keeps playback running when a tray exists.
Choose Quit to exit and save your settings.

Favorites, history, and settings are stored in:
%LOCALAPPDATA%\DNBRADIO\DNBRADIO
Deleting the extracted application folder does not delete your library.
There is no automatic updater. Exit the old version before extracting updates.

Report problems:
https://github.com/dnbradio/dnbradio-os-player/issues
BUILD-INFO.json identifies the exact source used for this Windows build.
